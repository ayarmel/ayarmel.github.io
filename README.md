# aaronyarmel.com

Personal website of Aaron J. Yarmel. Single self-contained page: `index.html`
(all CSS/JS inline, headshot embedded).

## Files
- `index.html` — the whole site
- `CNAME` — tells GitHub Pages the custom domain (www.aaronyarmel.com)
- `headshot.jpg` — used only for social-share previews (og:image)
- `cv.pdf` — ADD THIS: the Curriculum Vitae button links to it

## To update the site
Edit `index.html` (or replace it) and commit. GitHub Pages redeploys
automatically in about a minute.

## Known loose end
Two photos (Teaching and Counseling sections) are still hotlinked from
philosophycc.com's Squarespace CDN. If that site ever goes away, replace those
two <img src="https://images.squarespace-cdn.com/..."> URLs with local files
committed to this repo.
